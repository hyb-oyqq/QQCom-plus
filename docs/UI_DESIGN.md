# QQCom 界面与使用约定

## 端口选择

主界面固定 A/B 两行端点，类型和常用参数直接展示，高级参数在当前行下方展开；监视区、发送区、快捷指令通过分隔条调整。动作按钮表达当前操作：连接/断开、监听/停止、绑定/解绑。TCP 客户端还在拨号时，按钮文字改为「正在连接」，颜色保持未连接的蓝；再点一次取消。已打开的端口按钮为红。字段错误通过边框和悬停原因提示，状态及离散事件进入日志。A/B 桥接建立后，按钮同样变为红色，文字是「停止桥接」。

| 类型 | 常用配置 | 注意事项 |
| --- | --- | --- |
| 串口 | COM 名称及设备描述、波特率 | 数据位/校验/停止位/流控在高级设置；可输入自定义波特率 |
| TCP 客户端 | 对端 IPv4 或主机名、对端端口 | 异步连接，支持超时；拨号期间按钮显示「正在连接」。连上后数据区写一条带对端地址的「已打开」 |
| TCP 服务器 | 本地网卡、本地端口 | peer 身份保留到数据记录；监听成功不代表已有客户端。每个客户端握手完成后，数据区写「客户端 IP:端口 已连接」 |
| UDP | 本地网卡、本地端口、可选目标 IP/端口 | 本地地址用于接收，目标地址用于发送。首次收到某个来源的数据报时，数据区写「对端 IP:端口 已连接」 |

TCP 服务器/UDP 本地地址从网卡列表选择，保存 itemData 中的 IP，不解析显示文本。条目完整显示“网卡名称 · IPv4 地址”；选中项及下拉列表都不使用省略号，按内容和字体尺寸撑开。`0.0.0.0` 表示监听所有 IPv4 网卡，不是发送给对端的地址。

本地端口 `0` 表示由系统分配，绑定成功日志显示实际端口；需要让外部设备固定访问时使用明确端口。串口波特率文本区域至少容纳 `2000000`，同时考虑样式边框、箭头和 DPI。A/B 首列对齐，但不能以裁剪地址/波特率换取窄布局。

串口后台约每 2 秒扫描，列表仅在快照变化时更新。拔出后保留原选项并提示不可用，不自动连接其他设备。主参数行上的「自动恢复」默认关闭，放在高级按钮前面；切到 TCP 服务器时隐藏。勾选后，异常断开会每 1 秒重试一次：串口先等一次新扫描，确认上次那个口还在才打开，避免用拔出前的旧列表空打；TCP 客户端和 UDP 按间隔重连。TCP 服务器不重试，客户端断开后监听保持，要由客户端再连。打开失败只再记一条等待说明，不每拍重复错误。点「停止」取消本次恢复，勾选本身保留，下次启动仍记得。网卡列表目前在控件创建时枚举，运行期间网卡热插拔刷新仍待完善。

## UDP 来源与发送

UDP 没有握手。绑定成功后可收数据；第一次收到某个来源的数据报时，数据区记「对端 IP:端口 已连接」。这只说明这个来源出现过，不会自动把该来源设为发送目标。

- 目标 IP 留空时只接收，发送不可用。需要回复时填写明确的目标 IP 和端口。
- 收发记录在方向后带上对端 `IP:端口`。接收用 `<<--` 标来源，发送用 `-->>` 标写出目标。串口没有对端，箭头仍然画出，后面不跟地址。状态、警告、错误不画箭头。TCP 服务器一次写给多个客户端时，日志无法归到某一个地址。前缀只用 ASCII：`RX`、`TX`、`TX+FWD`、`TX+MAN`、`TX+TIMER`、`TX+SAMPLE`、`STATE`、`WARN`、`ERR`。屏幕上一行按内容拼接，顺序是行号、时间、端口、方向、字节数、箭头、对端，中间不补空格。字节数只出现在 RX/TX；STATE、WARN、ERR 没有载荷，不标长度。关掉方向时，RX/TX 的字节数改放在时间和冒号之间。文件日志和导出仍是制表符分隔。
- 首次收到某个来源时，数据区写一条状态：「对端 IP:端口 已连接」。同一来源不重复写。隐藏状态分类会隐藏这条日志。来源列表不是在线连接列表，也不改发送目标。
- 默认 UDP 本地端口为 `0`；跨机器测试需告知对端实际绑定地址/端口，并确保防火墙放行。

## 接收组帧

| 模式 | 输出时机 |
| --- | --- |
| 不拆分（默认） | 每次收到数据直接输出，不缓存 |
| 空闲超时 | 从最后一次非空数据到达起，连续无新数据达到设定时间后输出 |
| 结束符 | 找到完整结束符即输出，支持跨多次接收匹配 |
| U16 小端长度前缀 | 前 2 字节给出后续 payload 长度，完整时输出 |

空闲默认 **10 ms**。例如 0 ms 收到 A，8 ms 收到 B，则应从 8 ms 重新计时，约 18 ms 后仍无新数据才输出 AB，不能从首字节开始算固定窗口。Qt 定时器在系统繁忙时可能晚触发。

所有缓存模式同时支持长度兜底，默认 **2048 字节**；结束符与长度前缀模式也会因空闲输出未完成片段。关闭端点、TCP peer 离线和正常退出程序时输出缓冲最后的数据，保留真实来源。强制终止进程不属于正常关闭流程。

结束符默认不包含在输出中，长度前缀默认保留。组帧提示默认关闭，开启后记录兜底原因。TCP 服务器按 peer 分别缓存和计时，不把不同客户端拼成一帧。UDP 始终以数据报为边界，不应用上述组帧设置。

## 过滤与显示

端点和 RX/TX/转发/状态/警告/错误按结构字段筛选。关键词、排除词用英文逗号分隔，去掉首尾空白；多关键词任一命中即满足，多排除词任一命中即拒绝。支持大小写开关，当前为字面子串匹配，不支持正则表达式。

数据区顶栏从左到右是编码、过滤、A/B、RX/TX/转发、前缀、HEX、换行，右侧是设置、导出、滚动、清空、扩展。顶栏这三个显示开关用短名；「设置」菜单里写成「显示前缀」「始终显示HEX」「自动换行」。程序初次启动时扩展区收起；之后用户展开或收起的选择会被记住，下次按上次的状态打开。扩展区收起后，它和数据区之间的左右拖动条隐藏，并且不再占宽度；数据区左右离窗口边的距离保持一致。展开后拖动条回到原位。A/B 使能时为黄，未使能时为灰。勾选「显示前缀」后才显示端口、收发方向、前缀行号、前缀时间戳和前缀数据长度；关掉后只留数据，菜单里这三项变灰。端口方向没有单独开关，跟着「显示前缀」。「始终显示HEX」在数据行之后另起一行显示 HEX 对照；显示格式已经是 HEX 时自动省略。「自动换行」按窗口宽度折行。「滚动」勾选时始终跟到最新记录。没有保存过偏好时，「设置」里的显示前缀、前缀行号、前缀时间戳、显示状态、显示警告、显示错误勾上，前缀数据长度、始终显示HEX、自动换行关闭，「滚动」打开，「扩展」关闭。之后按上次保存的勾选打开。

数据区顶栏的「转发」开关只决定桥接产生的发送行是否出现在数据区。关掉后转发仍按原样进行，手动发送和接收不受影响。建立桥接和停止桥接各写一条状态，正文写明方向和两端端口。这条状态不属于 A 或 B，A、B 只要有一端还在显示就留下；两端都关掉时一起隐藏。隐藏状态分类也会隐藏它。

底部状态栏右侧，「检查更新」和窗口置顶各占一块浅底，中间留出与端点状态相同的间隔。正常启动约 3 秒后自动检查更新；环境变量 `QQCOM_DISABLE_UPDATE=1` 只关闭这次自动检查，手动按钮仍然可用。快照和延迟探针不检查。

搜索候选包含对端、端点名、状态说明、详情、当前编码文本、UTF-8 及两种 HEX 写法。关键词和排除词改变后立即作用于后续数据；已有历史要等点击「应用过滤」才按这两个框重新筛选。「清除过滤」暂停过滤并显示历史，保留输入词供再次应用。

A、B、RX、TX、转发、前缀、HEX、换行，以及设置菜单里的状态、警告、错误，一点就作用到已经收到的行，不用再点「应用过滤」。改前缀、HEX、换行或编码时，历史仍按上次已应用的关键词和排除词重绘。若关键词只在某种编码文本中存在，切换编码后命中结果可能变化，这是同一条件重新求值的结果。

时间、端口、对端、长度、HEX、换行、前缀及滚动跟随由「设置」菜单和顶栏同名开关控制。手动滚动取消跟随。缓冲释放必须提示；模型已释放的数据无法在下一次历史重绘时恢复。

## 发送与指令

发送区分为「手动发送」「发送文件」「接收文件」三个标签。手动发送前先校验编码、生成最终字节预览，再投递选中的 A/B 目标；定时发送按设定间隔发送主输入框内容。手动输入框的正文在下次启动时原样恢复，清空后也保持空白。发送成功表示本机接受写入，不是对端确认。

文件收发单独选择端点、RAW、XMODEM 或 YMODEM，以及发送/接收方向。XMODEM 固定 128 字节块，按对端启动字节在 CRC16 和 1 字节校验和之间兼容，收发都选本地文件。YMODEM 接收选目录。前置指令和后置指令在页内填写，各自可以设置等待时间。等待期间的字节不进入文件。进行中显示速度、字节进度、重试、CRC 错误，以及文件载荷的 CRC16 与 CRC32。

快捷指令支持分组增删和**重命名当前分组**，每条指令的说明仍在行内编辑。支持勾选、拖动排序、单条发送、按各行延时批量顺序发送。按钮左侧的「循环发送」勾上后，同一批勾选指令发完最后一条回到第一条，按钮变为「停止循环」，再点一次停止。组列表没有独立的周期任务管理器。导入/导出支持 QQCom JSON、JCom `.port`、BLE `.blemsg`；外部格式不支持的字段不能保证无损往返。

## 日志与导出

文本记录按会话创建带时间戳的新文件，启动记录、清空会话和手动重新开启记录均遵循新建语义。未手动指定目录时写到程序目录下的 `log` 文件夹，默认基名 `QQCom-log`。「设置」菜单中的「打开当前日志」用系统默认程序打开正在写入的那一份，未记录时不可点；「日志位置」可改目录，「恢复默认位置」回到该文件夹。文件头含产品名、时间和编码，记录期间切换编码会插入格式变更标记；正常关闭写完待记录批次。

TSV 导出是当前历史模型的预览，不是完整原始抓包；超过单条预览上限的数据带有截断信息。文件日志与显示过滤独立，但记录内容仍按当前实现的预览/编码路径生成。当前没有文件轮转、磁盘配额、后台写盘或完整抓包回放。
