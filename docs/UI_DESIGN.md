# 界面与端口控件设计

状态：主页面初版界面已实现，真实通信尚未接入。当前实现用于验证布局、交互和数据模型；首版采用 Qt Widgets，默认中文，字符串使用 tr() 保留翻译能力。

主区域用 QSplitter 调整比例；端口列表、数据监视和下方工具区可独立调整。当前原型默认创建四个未打开端口，分别覆盖串口、TCP 客户端、TCP 服务器和 UDP；添加同类型端口不需要复制主窗口。切换选中端口只切换编辑器和筛选，不会关闭其他端口。示例数据载入和端口配置变更已经可操作，但通信状态仍显示为预览状态。

## 2. PortSelectorWidget

参考 `portmanager + QComboBox + QStackedWidget` 的组合，已经封装成独立 QWidget：类型选择、配置页容器、打开/关闭按钮占位、状态、错误摘要。当前控件只维护端口草稿，不持有通信对象。

控件接受 EndpointConfig 和 StateSnapshot，发出 configEdited、openRequested、closeRequested 等意图；不持有通信对象。配置页注册表使用稳定的 PortType 标识，翻译、排序或增加页面不改变配置含义。通过 setCurrentWidget 切换页面，不使用 index+1 等隐含占位规则。

| 页面 | 常用项 | 高级项/状态 |
| --- | --- | --- |
| 串口 | 端口名＋描述、波特率、刷新 | 数据位 5/6/7/8、校验、停止位、流控；序列号/VID/PID；实际参数应用失败的原因 |
| TCP 客户端 | 远端地址/主机名、远端端口 | 连接超时、重连开关、退避状态、可选低延迟选项；默认直连 NoProxy |
| TCP 服务器 | 本地绑定地址、监听端口 | 最大客户端数；peer 列表（地址、连接时间、收发、积压）；指定/全部发送、断开选中客户端 |
| UDP | 本地地址/端口、固定目的 IP/端口 | 最近来源列表、选择某来源作为目的地址、广播开关、最大数据报长度 |

首次配置 TCP Server/UDP 默认绑定 127.0.0.1，列表提供“所有网卡”及实际网卡地址；监听所有网卡由用户选择。本地端口 0 表示自动分配，绑定成功后展示实际端口。UDP 可只接收，未选择目的地址时禁用发送。

串口列表将系统标识存入 itemData，描述文字可变化；刷新保留用户选项，消失项标为“设备不可用”。后台刷新结果不触发自动重开。开始连接后锁定类型及影响链路的参数，允许“取消连接”；参数修改在关闭后生效。

## 3. 状态与错误反馈

用文字加图标区分“关闭、连接中、已连接、监听中、已绑定、重连等待、关闭中、错误”。颜色仅为辅助，不把 TCP listener 或 UDP bound 显示成“已连接远端”。

参数错误在字段附近显示，运行错误在状态区给出原因和重试入口；重复错误合并并显示次数，避免连续模态 QMessageBox 阻塞调试。删除已打开端口时走统一关闭流程；相关路由和定时任务显示失效目标。

TCP 客户端列表按 PeerId 绑定选择；连接消失后显示“原客户端已断开，请重新选择”，新连接不会继承旧选择。所有端口的关闭和停止按钮在高负载期间始终可用。

## 4. 数据监视

RX 与 TX 使用不同颜色/方向标识；发送显示“已入队、写入中、本地完成、失败”，提示“本地完成不代表对端应用收到”。可按端口、客户端、方向筛选；筛选不改变实际收发或转发。

HEX 和文本切换只作用于预览。文本默认 UTF-8，可选 Latin-1；NUL/控制字节可用可见转义呈现，非法 UTF-8 有替换标记和 HEX 查看入口。选择记录可查看元数据、复制已保留字节、再次填入发送区，发送前重新确认当前目标。

时间戳使用毫秒显示，可展开单调时差。流片段标记为“数据片段”，UDP 标记为“数据报”，避免让用户把 TCP readyRead 分块误认为协议帧。

- 暂停：冻结当前视图，后台继续通信；恢复时显示遗漏记录数。
- 清空：只清除显示历史；另设“重置统计”。
- 自动滚动：用户滚动查看旧数据时停止跟随，点击“跟随最新”恢复。
- 容量：始终提示截断/淘汰数量，大数据记录显示“预览前 N 字节，共 M 字节”。
- 完整记录：通过独立按钮开启，显示路径、已写入量和完整性状态。

## 5. 转发规则编辑

规则表字段：启用、名称、源端口、来源客户端过滤、目标端口、目标模式/地址、分包策略、拥塞策略、状态、字节计数。提供“创建双向桥”快捷入口，最终生成两条可单独查看的规则。

串口 A ↔ TCP Server B 的向导：

1. 选择 A、B，配置 A→B 的固定客户端或全部客户端。
2. 为 B→A 选择单一来源客户端；需要混合来源时显式启用“全部客户端汇聚”。
3. 展示两条规则和拥塞处理方式；启用后显示等待/运行/拥塞状态。

流→UDP 时必须显示分包选择，默认推荐 1200 字节＋10 ms 尾部刷新；界面解释数据块边界可能变化。UDP→流提示边界会消失。固定 peer 已失效、无 UDP 目标、重复/自转发规则时不能启用。

“停止全部转发”立即停止新路由数据准入，结算未完成请求；已进入操作系统的数据可能继续发出，状态区标出剩余本地完成量。

## 6. 自定义发送

单次发送提供目标、目标 peer/UDP 地址、模式、编码、正文、尾部及最终字节预览。非法 HEX/转义显示错误位置和原因，发送按钮不可用。切换文本/HEX 模式不偷偷转换或改写输入，必要时提供明确的“转换内容”动作。

命令列表字段：启用、名称、目标、模式、内容、尾部、间隔、次数、结果。支持增删、复制、上下移动、单行发送、选中行顺序循环、导入导出。

周期任务启动后展示目标快照、已完成次数、missedTicks 和停止按钮；断线自动停止，目标改变不自动续发。间隔为调度目标，UI 不显示硬实时保证。

## 7. 交互验收

在 1280×720、1920×1080 及 100%/150%/200% 缩放下检查关键控件可见、布局无覆盖；端口参数长描述支持提示而非拉宽整个窗口。常用字段有 label 与 Tab 顺序，图标按钮有文字提示，错误和状态不能只靠颜色识别。
