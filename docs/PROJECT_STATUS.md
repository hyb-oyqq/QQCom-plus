## 一、项目概况

easyDebug 是一个双端点通信调试工具，支持串口、TCP、UDP 四种端点类型。项目采用分层架构，清晰分离 domain、transport、app 和 UI 层。

## 五、代码质量

### 架构优点

✅ **分层清晰** - domain → transport → app → ui，依赖方向正确  
✅ **职责单一** - 每个类职责明确，无上帝对象  
✅ **组合根真正只装配** - MainWindow 不执行业务逻辑  
✅ **编解码单一真源** - PayloadCodec 统一处理所有格式  
✅ **无全局单例** - 显式依赖注入，可测试性强  

### 已修复问题（2026-10-02）

✅ `.pri` 文件拆分 - domain/discovery/persistence 独立  
✅ 端点类型索引解耦 - 使用枚举值而非下标  
✅ include 路径统一 - 项目根相对路径  
✅ 自由函数提取 - endpointformat.h / combometrics.h  
✅ 零引用组件清理 - 删除未使用的自绘控件  
✅ 对话框样式统一 - styledialogs.h 封装  

### 待优化项

⚠️ **暗色模式支持** - workbench-dark.qss 已创建，待集成  
⚠️ **i18n 链路** - 空翻译文件待补全或移除  
⚠️ **版本脚本跨平台** - Windows 专用，其他平台需处理
