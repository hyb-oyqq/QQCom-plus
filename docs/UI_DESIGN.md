# QQCom 界面与使用约定

## 端口选择

主界面固定 A/B 两行端点，类型和常用参数直接展示，高级参数在当前行下方展开；监视区、发送区、快捷指令通过分隔条调整。动作按钮表达当前操作：连接/断开、监听/停止、绑定/解绑。字段错误通过边框和悬停原因提示，状态及离散事件进入日志。

| 类型 | 常用配置 | 注意事项 |
| --- | --- | --- |
| 串口 | COM 名称及设备描述、波特率 | 数据位/校验/停止位/流控在高级设置；可输入自定义波特率 |
| TCP 客户端 | 对端 IPv4 或主机名、对端端口 | 异步连接，支持超时；通信状态由后端回报 |
| TCP 服务器 | 本地网卡、本地端口 | peer 身份保留到数据记录；监听成功不代表已有客户端 |
| UDP | 本地网卡、本地端口、可选目标 IP/端口 | 本地地址用于接收，目标地址用于发送 |

TCP 服务器/UDP 本地地址从网卡列表选择，保存 itemData 中的 IP，不解析显示文本。条目完整显示“网卡名称 · IPv4 地址”；选中项及下拉列表都不使用省略号，按内容和字体尺寸撑开。`0.0.0.0` 表示监听所有 IPv4 网卡，不是发送给对端的地址。

本地端口 `0` 表示由系统分配，绑定成功日志显示实际端口；需要让外部设备固定访问时使用明确端口。串口波特率文本区域至少容纳 `2000000`，同时考虑样式边框、箭头和 DPI。A/B 首列对齐，但不能以裁剪地址/波特率换取窄布局。

串口后台约每 2 秒扫描，列表仅在快照变化时更新。拔出后保留原选项并提示不可用，不自动连接其他设备。网卡列表目前在控件创建时枚举，运行期间网卡热插拔刷新仍待完善。

## UDP 来源与发送

UDP 是无连接通信。绑定成功后可收数据，收到数据报不表示对端“连接成功”，也不会自动将最后一个来源设为发送目标。

- 目标 IP 留空时只接收，发送不可用。需要回复时填写明确的目标 IP 和端口。
- 接收记录携带来源 `IP:端口`，新来源事件与接收来源提示用于区分发送设备；来源列表不是在线连接列表。
- 显示设置可控制每条数据的对端字段。来源事件属于状态记录，隐藏状态分类会隐藏相应日志。
- 默认 UDP 本地端口为 `0`；跨机器测试需告知对端实际绑定地址/端口，并确保防火墙放行。

## 接收组帧

| 模式 | 输出时机 |
| --- | --- |
| 不拆分（默认） | 每次收到数据直接输出，不缓存 |
| 空闲超时 | 从最后一次非空数据到达起，连续无新数据达到设定时间后输出 |
| 结束符 | 找到完整结束符即输出，支持跨多次接收匹配 |
| U16 小端长度前缀 | 前 2 字节给出后续 payload 长度，完整时输出 |

空闲默认 **10 ms**。例如 0 ms 收到 A，8 ms 收到 B，则应从 8 ms 重新计时，约 18 ms 后仍无新数据才输出 AB，不能从首字节开始算固定窗口。Qt 定时器在系统繁忙时可能晚触发。

所有缓存模式同时支持长度兜底，默认 **300 字节**；结束符与长度前缀模式也会因空闲输出未完成片段。关闭端点、TCP peer 离线和正常退出程序时输出缓冲最后的数据，保留真实来源。强制终止进程不属于正常关闭流程。

结束符默认不包含在输出中，长度前缀默认保留。组帧提示默认关闭，开启后记录兜底原因。TCP 服务器按 peer 分别缓存和计时，不把不同客户端拼成一帧。UDP 始终以数据报为边界，不应用上述组帧设置。

## 过滤与显示

端点和 RX/TX/状态/警告/错误按结构字段筛选。关键词、排除词用英文逗号分隔，去掉首尾空白；多关键词任一命中即满足，多排除词任一命中即拒绝。支持大小写开关，当前为字面子串匹配，不支持正则表达式。

搜索候选包含对端、端点名、状态说明、详情、当前编码文本、UTF-8 及两种 HEX 写法。条件改变立即作用于后续数据；已有历史在点击“应用过滤”时重新筛选。“清除过滤”暂停过滤并显示历史，保留输入词供再次应用。

修改显示开关或编码只用已应用条件重绘历史，不偷偷应用尚未确认的输入。若关键词只在某种编码文本中存在，切换编码后命中结果可能变化，这是同一条件重新求值的结果。

时间、端口、对端、长度、HEX 对照、换行、精简显示及滚动跟随由显示设置控制。手动滚动取消跟随。缓冲释放必须提示；模型已释放的数据无法在下一次历史重绘时恢复。

## 发送与指令

发送区分为「手动发送」和「文件收发」两个标签。手动发送前先校验编码、生成最终字节预览，再投递选中的 A/B 目标；定时发送按设定间隔发送主输入框内容。发送成功表示本机接受写入，不是对端确认。

文件收发单独选择端点、RAW 或 YMODEM，以及发送/接收方向。前置指令和后置指令取自快捷指令，各自可以设置等待时间。等待期间的字节不进入文件。进行中显示速度、字节进度、重试、CRC 错误，以及文件载荷的 CRC16 与 CRC32。

快捷指令支持分组增删和**重命名当前分组**，每条指令的说明仍在行内编辑。支持勾选、拖动排序、单条发送、按各行延时批量顺序发送；组列表没有独立的周期任务管理器。导入/导出支持 QQCom JSON、JCom `.port`、BLE `.blemsg`；外部格式不支持的字段不能保证无损往返。

## 日志与导出

文本记录按会话创建带时间戳的新文件，启动记录、清空会话和手动重新开启记录均遵循新建语义。默认基名 `QQCom-log`，文件头含产品名、时间和编码，记录期间切换编码会插入格式变更标记；正常关闭写完待记录批次。

TSV 导出是当前历史模型的预览，不是完整原始抓包；超过单条预览上限的数据带有截断信息。文件日志与显示过滤独立，但记录内容仍按当前实现的预览/编码路径生成。当前没有文件轮转、磁盘配额、后台写盘或完整抓包回放。
